# 💍 Wedding RSVP System

Site de casamento com confirmação de presença e gerenciamento de convidados.

## 📋 Sobre o Projeto

Este projeto é composto por um site de convite de casamento com frontend interativo e um backend para gerenciamento da lista de convidados, permitindo que os convidados confirmem presença online.

## 🗂️ Estrutura do Projeto

```
Casamento/
├── index.html          # Página principal do site
├── script.js           # Lógica do frontend
├── style.css           # Estilo da página
├── backend-casamento/
    ├── server.js       # Servidor Node.js
    ├── convidados      # Dados dos convidados
    ├── package.json
    └── package-lock.json
```

## 🚀 Como Rodar

### Frontend
Basta abrir o arquivo `index.html` no navegador.

### Backend
```bash
cd backend-casamento
npm install
node server.js
```

## 🛠️ Tecnologias

- HTML, CSS, JavaScript
- Node.js (backend)
